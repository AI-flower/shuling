# Emoji 词典（v3.0 _shared 资源）

> 被 03-daily-flow.md（草稿生成）和 08-compliance.md（禁用规则基线）共享。

| Emoji | 语义 | 示例 |
|---|---|---|
| 💡 | 小贴士 | `小贴士💡：先看官方文档再上手` |
| ⚠️ | 关键点/坑 | `关键点⚠️：要先关代理再启动` |
| ✅ | 重点/完成 | `✅ 装好了 ✅ 跑通了` |
| ✨ | 收尾/高光 | `搞定！享受丝滑体验✨` |
| 📝 | 笔记/记录 | `📝 笔记 1：xxx` |
| 🎯 | 目标/受众 | `🎯 适合：刚入坑的同学` |
| 🔥 | 热门 | `🔥 最近很火的 X` |
| 💯 | 强推 | `💯 真心好用` |
| 主题 emoji（如 ☕ 🍌 🧺） | 标题 1 个，强化记忆点 | `5 个收纳技巧🧺，桌面清爽一半` |

⚠️ **总量控制**：标题 1-2 个 emoji；正文每段最多 1 个；不要 4 个 emoji 排排坐。
