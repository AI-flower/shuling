## 总目标

v3.1 把账号写操作（publish / comment / import-cookie）从「普通脚本能力」降级为「需要 approval 的 privileged mutation」，把外部数据采样从「散落调用」收口为「预算化情报层」。`bash ops/verify/pre-submit-verify.sh --strict` 完成时从 v3.0 的 34 条扩到 42 条且全绿。

版本位决策：BRAIN +1（playbook 流程改 + 默认行为变）/ HANDS +1（新脚本 + schema）/ CALIB +1 → **v3.1.0**（major minor，非 breaking 但需迁移）。
